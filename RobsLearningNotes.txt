AI Navigation Toolbox
- Nav mesh areas: different cost multipliers for different areas (different for different agent types)
- Render meshes vs physics colliders
- Nav surface volumes
- Nav quality None (when gathering resources) and High when navigating
- Nav priority: can push others out of the way (lower priority number is more powerful)
- NavMeshModifiers and NavMeshModifiersVolumes: used to manipulate Areas when baking NavMesh
- NavMeshObstacle: allows nav mesh to be effectively modifified at runtime through "carvingf", without requiring re-bake
- Long story short: Use NavMeshModifierVolumes to change bake, and use NavMeshObstacle to change at runtime.
- "Unit Dancing" problem: multiple nav agents with the same priority. Set new nav positions based on number of selected units

Event Bus
- Loose coupling / sollution to interclass comms (Bus.cs example)

- "public static void Raise(T evt) => OnEvent?.Invoke(evt);" // expression bodied function
